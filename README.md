# EGK（EggKingdom）公式サイト

v0で作成したNext.jsの画面を引き継ぐリポジトリです。**現在は開発用の表示と端末内カートが中心です。会員登録、注文確定、決済、メール送信、管理画面、大会ライブ連携は未実装です。**

## 起動

Node.js 22 LTS以降、pnpm（`package.json`指定は12.3.4）を用意します。Windowsでもプロジェクトフォルダをターミナルで開き、同じコマンドを実行できます。Corepackを導入済みなら `corepack enable` でpnpmを有効にできます。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

`http://localhost:3000` を開きます。通常の画面確認に外部サービスの秘密鍵は不要です。

必要に応じて `.env.example` を `.env.local` にコピーし、`NEXT_PUBLIC_SITE_URL` を自分の確認用URLへ変更します。Windows PowerShellは `Copy-Item .env.example .env.local`、macOS/Linuxは `cp .env.example .env.local` でコピーできます。

## チェックと本番起動

```sh
pnpm typecheck
pnpm build
pnpm start
```

`pnpm check` は型チェック→本番ビルドを順番に実行します。型エラーを無視する設定は削除しました。Google Fontsをビルド時に取得するため、初回ビルド時にその配信先へ接続できる環境が必要です。

## 画面の確認手順

1. ホームのバナー、記事、商品へ移動する。
2. メンバー一覧から個人ページを開く。
3. 商品の選択肢を選び、カートへ追加。数量変更・削除と再読み込み後の保持を確認する。
4. 購入手続きでは未接続と表示され、実際の注文は送信できないことを確認する。
5. JP / ENで同じページの文言とヘッダー表示言語が変わるか確認する。
6. スマートフォン幅で下部4項目とメニュー内リンク、右上の言語切り替えを確認する。
7. 大会では未接続、ログイン・登録・問い合わせでは送信不可の表示を確認する。

上記は操作手順です。実施結果・未実施項目はSTATUS.mdに記録します。

## 構成

| パス | 役割 |
| --- | --- |
| `app/` | 公開ページ・会員画面のルート |
| `components/site/` | ヘッダー、下部メニュー、言語切替など |
| `components/shop/` | 商品選択と端末内カート |
| `lib/data/dev-data.ts` | 人物・商品・価格・結果などの開発用サンプル |
| `lib/data/index.ts` | ページからデータを読み出す境界。将来DBへ置換 |
| `lib/types.ts` | データ型と翻訳状態 |
| `lib/i18n/` | 日英の画面文言、言語Cookie、翻訳フォールバック |
| `public/images/dev/` | 開発用画像。正式素材ではない |

カートはlocalStorageへ商品識別子と数量を保存するだけです。本番の価格・在庫検証や決済処理はまだ存在しません。コメントの将来方針を実装済みの保証として扱わないでください。

## 引き継ぎ

- `SPEC.md`：ユーザーと決めた仕様
- `DESIGN.md`：画面とデザインルール
- `STATUS.md`：実装状況、検証結果、次の作業
- `.env.example`：現在使う環境変数の見本

AIや担当者が変わるときは最新版のコードと上記を一緒に読んでください。同じブランチを複数のツールで同時編集せず、機能ごとに変更をまとめます。

## 公開前

今は `isUsingDevData = true` で、告知帯・noindex・robotsの巡回禁止が有効です。単にfalseに変えても実データへ切り替わりません。DB・正式素材・権限・決済・販売条件を準備してから解除してください。

`.env.local`、秘密鍵、決済やメールのAPIキーはコミットしません。新しい外部サービスは契約先を確認し、必要な設定項目だけを `.env.example` に追加します。
